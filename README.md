# 🚀 多機能 LINE メディア保存 Bot (GAS/clasp)

LINEで送信された画像、動画、ファイルをGoogle Driveに自動保存し、スプレッドシートで一元管理する高度なボットです。

## ✨ 主な機能

### 📂 メディア自動保存
- **自動フォルダ分け**: グループ/ユーザーごと、かつ日付（YYYYMMDD）ごとにフォルダを自動生成。
- **ログ記録**: 保存した各メディアの「日時、ユーザー名、ファイル名、メモ、URL」を、チャットごとの専用スプレッドシートに記録。
- **共有設定**: 作成されたログスプレッドシートは「リンクを知っている全員が閲覧可能」に自動設定されます。

### 📝 高度なリネーム (/rename)
- **通常**: `/rename [名前]` - 直前に保存したファイルをリネーム。
- **番号指定**: `/rename [数字] [名前]` - 本日の保存履歴から `[数字]` 番目に新しいファイルをリネーム。
- **一括**: `/rename all [名前]` - 本日の全ファイルに連番を付けて一括リネーム。
- **仕様**: 拡張子は自動維持。ドライブとログSSの両方が同期して書き換わります。

### ✍️ メモ追記 (/memo)
- **通常**: `/memo [内容]` - 直前に保存したファイルにメモを追記。
- **番号指定**: `/memo [数字] [内容]` - 本日の `[数字]` 番目に新しいファイルにメモを記録。
- **仕様**: スプレッドシートの「メモ」欄が更新されます。

### 🗑️ ファイル削除 (/delete)
- `/delete` - 直前に保存したファイルを即座にゴミ箱へ移動。

### 📁 閲覧・管理
- **/list**: 本日保存したファイル名の一覧を表示。
- **/link**: 保存先フォルダのURLを表示（ログSSへのアクセスもここから）。

### ⚙️ 設定・その他
- **/reply [on/off]**: グループ内での保存完了通知（Flexメッセージ）の表示切替。
- **/debug**: システムの接続状況（フォルダ、SS、管理者設定）を自己診断。
- **/contact**: 開発者への直接フィードバック（要望・バグ報告）。

### 👮 管理者専用機能
- **秘密ログ機能**: すべてのトーク内容（テキスト・メディア履歴）を管理用秘密スプレッドシートに別途記録（※非公開設定）。
- **/admin register**: 初回実行時に管理者を登録。システムエラー等がここに通知されます。

## 🛠️ 技術スタック
- **Runtime**: Google Apps Script (V8 engine)
- **Tool**: clasp (Command Line Apps Script Projects)
- **API**: LINE Messaging API
- **Storage**: Google Drive, Google Sheets
